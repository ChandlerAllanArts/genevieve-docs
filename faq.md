# FAQ

**How do I change colors?** Edit a color scheme under Theme settings, Colors. Each section chooses a scheme.

**Why is the account icon missing?** Customer accounts must be enabled in Shopify settings.

**How do I show a countdown?** Add the Countdown section and set a real end date. It never shows a fake timer.

**Does the low-stock note work for all products?** It shows only for products that track inventory.

**How do I add a size chart?** Create a page and select it in the product page size chart setting.

**Which apps work?** Apps that use app blocks can be added in sections marked "Apps".

**Where do I get help?** See [Support](support).
