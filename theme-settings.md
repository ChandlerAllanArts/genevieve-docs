# Theme settings

Open the theme editor, then choose **Theme settings** (the paintbrush icon). These settings apply to the whole store.

## Logo

| Setting | What it does |
| --- | --- |
| Logo style | Choose: Built-in crest and wordmark, Uploaded image |
| Wordmark small line |  Optional small line above the name. |
| Wordmark name |  Leave blank to use the store name. |
| Crest monogram |  One or two letters. Leave blank to use the first letter of the name. |
| Logo image | Image |
| Logo width | 60 to 300 px. default: 140 |
| Favicon | Image |

## Typography

| Setting | What it does |

| Body | default: cormorant_n4 |

| Italic headings | On or off. default: false |

## Colors

Genevieve uses **color schemes**. A scheme is a set of colors: background, text, buttons, borders and an accent. You edit up to five schemes here, then each section chooses which scheme it uses. In every preset the five schemes have the same roles:

| Scheme | Role |
| --- | --- |
| Scheme 1 | Page: the default background |
| Scheme 2 | Surface: a slightly different panel color |
| Scheme 3 | Band: a stronger band for announcements and highlights |
| Scheme 4 | Inverse: the opposite of the page |
| Scheme 5 | Overlay: light text on a dark color, used on top of photographs |

| Setting | What it does |
| --- | --- |
| Page color scheme | Pick one of your color schemes. default: scheme-1 |
